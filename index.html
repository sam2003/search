Search Maharashtra Property-Registration (IGR) Records

Load the Excel exports from the Maharashtra registration portal and search across all of them at once — by document number, type, party name, or property description. Everything runs in your own browser: the files are never uploaded to any server.

What this tool is for

The Department of Registration & Stamps (IGR), Government of Maharashtra, publishes an index of registered documents — sales, gifts, releases, leases and more — through its public search service. That service returns one search at a time as a downloadable spreadsheet. In real title-search or due-diligence work you gather many such exports across different areas, years and name spellings, and the questions that matter cut across all of them at once: where does this name appear as a buyer or a seller, in any of these files?

Opening each spreadsheet by hand to answer that is slow. This tool loads every export together and searches them as one set, returning matching rows from all of them in a single table you can page through and download. Files are read once when you add them, held only in your browser's memory, and gone the moment you close or refresh the page.

How to use it, step by step

  1. Export from the IGR portal. Run your search on the department's public property-search service and download the result as a spreadsheet. The file usually has an .xls name but is really an HTML table in UTF-16 — this tool reads that directly, so you do not need to convert it first.
  2. Add the files. Drag files or a whole folder onto the drop zone at the top of this page, or click it to pick files. Each file is read once as it is added; after that, searches are instant. Adding more files later adds to the set rather than replacing it, and you can remove any single file with the × beside its name.
  3. Filter. Every box is optional. Use Search any column for a broad look, or the specific boxes — Document no, Document type, Seller, Purchaser, Property contains. Seller and Purchaser match loosely, ignoring spaces and braces, because the portal exports names run together.
  4. Read and export. Matches appear in the table above, paged for speed, with any-column matches highlighted. Download CSV saves the current filtered set with Marathi text intact.

Common questions

Why does Excel warn when opening the export?

Because the portal's .xls files are HTML tables in disguise, saved in Unicode. That is normal. Load them into this tool as they came off the portal — do not re-save them through another program, as that can garble the Marathi text.

A party name will not match — why?

Names are often exported without spaces and inside braces. Use the Seller or Purchaser boxes, which match loosely, and try a shorter fragment of the name rather than the full string.

Are my files uploaded anywhere?

No. There is no server behind this tool. Your browser reads the files directly off your own disk and holds the rows in memory for the life of the page. Refreshing, closing the tab, or pressing Clear all files discards them. See the privacy policy for detail.
